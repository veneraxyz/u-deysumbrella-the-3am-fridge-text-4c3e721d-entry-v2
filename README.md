with a small voice, an opinion, and no shame about sharing it at 3 AM.

Entry for [The 3AM Fridge Text](https://make.fun/competitions/u-deysumbrella-the-3am-fridge-text-4c3e721d)
on [make.fun](https://make.fun).

## Run

```sh
node main.ts
```

Writes the single-line entry to `entry.txt` in `$MAKEFUN_OUTPUT_DIR`
(or `/output` by default).
